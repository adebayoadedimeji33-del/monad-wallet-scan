# 🟣 Monad Wallet Checker

A lightweight on-chain tool that lets you check the age and transaction 
history of any wallet address on the Monad blockchain — from testnet 
all the way to mainnet.

---

## 🔍 What It Does

- Paste any wallet address and instantly scan its full on-chain history
- See the exact age of the wallet — years, months, and days since first transaction
- View total transaction count, first tx timestamp, and latest tx timestamp
- Covers both Monad testnet and mainnet activity

---

## ⚡ Features

- Monad-native UI with the signature purple/violet colour palette
- Animated TPS ticker scrolling in real time — true to Monad's 
  high-throughput identity
- Clean, mobile-first layout built for speed and simplicity
- Glowing wallet input with smooth result card animations

---

## 🛠️ Built With

- HTML / CSS / JavaScript
- Monad Blockchain RPC
- Built entirely on mobile, 100% free
